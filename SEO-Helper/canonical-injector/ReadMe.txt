1. 概要
----------------------------------------------------------------------
本ツールは、ローカルにある複数のHTMLファイルに対して、正規ページのURLを
指定する「Canonicalタグ」を再帰的に一括挿入・更新するための単体
デスクトップツールです。

ミラーサイト対策や、同一ページのURL表記揺れ・重複正規化などに活用でき、
指定フォルダ配下のHTMLファイルを自動スキャンして効率よく整理できます。


2. 主な機能
----------------------------------------------------------------------
・フォルダ選択ダイアログによるターゲットディレクトリの直感的指定
・ベースURLを指定した配下HTMLファイルの再帰的自動スキャン
・末尾の index.html を省略してディレクトリURL（/）に寄せるオプション搭載
  （既定で有効。チェックを外すことで元のファイルパスを維持可能）
・既存のCanonicalタグがあれば置換し、なければ </head> の直前に自動追加
・変更があったファイルのみ上書き保存し、処理結果をログエリアに逐次表示
・マルチスレッド処理による大量ファイル処理時のGUIフリーズ防止


3. 使い方
----------------------------------------------------------------------
1. Python 3.x 環境でスクリプトを実行します。(もしくはRun.bat)
2. 「ターゲットフォルダ」の「参照...」ボタンから、HTMLファイルが
   入っているフォルダを選択します。
3. 「ベースURL」に正規化先となるベースURL（例: https://example.com）を
   入力します。
4. 必要に応じて「index.html を省略してディレクトリURL (/) にする」の
   チェック状態を確認・変更します（初期状態はON）。
5. 「実行する」ボタンをクリックすると、処理ログが表示されながら
   自動で書き換えが行われます。


4. 依存ライブラリ
----------------------------------------------------------------------
本ツールはPython標準ライブラリ（tkinter 等）のみで動作するため、
追加の外部ライブラリインストールは不要です。
