1. 概要
----------------------------------------------------------------------
本ツールは、指定したWebサイト（URL）を巡回（クロール）し、サイト内の
内部リンク構造や接続関係をグラフィカルに可視化（マッピング）するとともに、
SEOやリンク設計上の重複・混在を診断する単体デスクトップツールです。

pyvisによる物理シミュレーション描画を用いて、各ページの結合状態やハブ構造、
孤立ページ、HTTPエラー（404等）、同一ディレクトリ内でのルート指定や
トップ相当ファイル名の重複・混在をインタラクティブなHTMLマップと
警告レポートとして出力・確認できます。


2. 主な機能
----------------------------------------------------------------------
・指定URL以下の内部リンクを自動巡回（同一ドメイン・ルートスキーム統一／
  クエリパラメータ正規化／最大ページ数上限設定対応）
・HTTPエラーや接続エラーの検知（エラーノードの色・形状分岐と警告表示）
・ルート(/)と既定ドキュメント候補(index, default, home, top, main, start等)の
  混在、および同一ディレクトリ内でのトップ相当ファイル名同士の重複検知
・重複・混在に関与するノードのマップ上での強調表示と、詳細を確認できる
  警告レポートウィンドウ・コンソール出力
・pyvisを使用した内部リンク構造のインタラクティブなHTMLマップ
  （site_link_map.html）自動生成およびブラウザ表示（100vh/100%追従）
・生成HTMLへのノード検索バー組込み（ファイル/パス検索、次へジャンプ、
  非該当ノードの減衰ハイライト、クリア対応）
・マルチスレッド処理によるGUIフリーズ防止


3. 使い方
----------------------------------------------------------------------
1. Python 3.x 環境でスクリプトを実行します。(もしくはRun.bat)
2. 「対象WebサイトのURL」に、解析したいサイトのURLを入力します。
   （例: https://example.com/）
3. 「最大巡回ページ数」を指定します（デフォルト: 200）。
4. 「解析スタート」ボタンを押すと、バックグラウンドでサイトのクロールと
   リンク構造・重複チェックが開始されます。
5. 解析が完了すると、自動的に「site_link_map.html」が生成され、
   既定のWebブラウザで可視化マップが開きます。
6. 完了ダイアログ後、ルート指定やトップ相当ファイルの混在・重複が
   検知された場合は「SEO・リンク構造 警告レポート」ウィンドウに
   対象ディレクトリ・種別・対象URL・参照元が表示されます。
7. 生成されたHTMLマップ画面右上の検索バーから、ファイル名やパスで
   対象ノードを検索・フォーカスできます。


4. 依存ライブラリ
----------------------------------------------------------------------
本ツールを実行するには、以下の外部ライブラリが必要です。

  pip install requests beautifulsoup4 pyvis
